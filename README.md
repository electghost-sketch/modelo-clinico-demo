# Habilitación Modelo Clínico — Demo

Primera versión de revisión visual e interactiva.

## Objetivo
Permitir que estudiantes, académicos y colaboradores consulten en un solo enlace:
- resumen de participantes;
- agenda semanal;
- búsqueda por nombre;
- grupo, fecha, horario, sala y actividad;
- orientaciones generales.

## Importante
Todos los nombres y asignaciones incluidos en esta versión son ficticios.

## Publicación
El proyecto es estático y puede publicarse gratis en GitHub Pages, Cloudflare Pages, Netlify u otro hosting estático.
